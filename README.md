# 这个是我们的团队github仓库，里面有简单的使用手册
#大家可以将写好的代码更新在这里

step 1:在vscode的终端箭头（>）之后填写：“git clone https://github.com/wunyongheng060108-source/Bit-Korean-Team-Storage/blob/main/drama-learn-hanyu” 然后按回车键
step 2:终端箭头（>）之后填写："cd drama-learn-hanyu"

step3: 写了代码想要保存（在终端箭头之后填写）

git add .                               # 加入所有改动
git commit -m "完成首页导航栏"           # 存档（说明这次改了什么）
git push                                  # 传到 GitHub
